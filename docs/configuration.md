# Configuration

## Python Requirements

Install dependencies used by current code:

```bash
pip install playwright curl-cffi pydantic python-dotenv
playwright install chromium
```

## Environment Variables

Set in project root `.env`:

- `LINKEDIN_EMAIL` or `LINKEDIN_USERNAME`
- `LINKEDIN_PASSWORD`
- `LI_COOKIE` (generated by session extractor)
- `LI_CSRF_TOKEN` (generated by session extractor)

Recommended minimal `.env` before first run:

```env
LINKEDIN_EMAIL=your_email
LINKEDIN_PASSWORD=your_password
```

Then run:

```bash
python -m module.session_extractor --test
```

This appends `LI_COOKIE` and `LI_CSRF_TOKEN` automatically.

## Output Paths

Paths are centralized in `module.paths`:

- `output/results/` for final search output.
- `output/progress/` for progress snapshots.
- `output/session/` for Playwright storage state.

## Session Refresh Controls

From `scraper.py`:

- `--refresh-session`: force refresh before search.
- `--headless`: run refresh browser headless.
- `--test-session`: validate current session and exit.

## Location Filtering Controls

- `--location` accepts city/country text.
- If text is not in built-in map, scraper calls LinkedIn geo typeahead and prompts selection.
- The selected geo ID is sent as `companyHqGeo`, plus client-side subtitle word matching is applied.
